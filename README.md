# База данных приложения для совместных поездок студентов

Групповой проект по дисциплине «Базы данных», НИУ ВШЭ, Высшая школа бизнеса, «Бизнес-информатика», 2026.

Студентам из одного города дорого и скучно ездить домой на каникулы поодиночке, а в BlaBlaCar и похожих сервисах нет ни проверки, что попутчик правда студент, ни привязки к датам сессий. Мы придумали приложение, где студенты находят попутчиков внутри своего сообщества и делят расходы, и спроектировали для него базу данных на PostgreSQL.

## Что внутри

7 таблиц: студенты, поездки, заявки, баланс поездки, чат (сообщения в `jsonb`), уведомления и модераторы. Статусы сделаны через `enum`, данные защищены ограничениями: уникальность почты и студенческого, формат почты и пароля, возраст, неотрицательные суммы, запрет оплаты отклоненной заявки и т.д.

Бизнес-логика вынесена в функции и представления: поиск поездок, проверка свободных мест, подбор замены отказавшемуся попутчику, модерация и блокировка за поздние отмены, чат, уведомления, финансовый отчет по поездке, заполненность поездок и рейтинг студентов.

На каждое ограничение и функцию написаны позитивные и негативные тесты.
